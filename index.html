LocalSend Retro

Share files with the official LocalSend app on phones and modern computers. Your old Mac shows up in its list, and you can send and receive in both directions.

Build it yourself today

  1. Install Xcode Tools on the old Mac. They include gcc.
  2. Download the source and unzip it.
  3. Open Terminal, go into the folder and run: sh build.sh
  4. Open LocalSend.app. Pick your Mac in the LocalSend app on your phone and send a file.

On Mac OS X 10.3 the build leaves out encryption. Sending to encrypted devices needs 10.4 or later.

Open the Mac OS 9 source

No ready-made application yet. You build it on the OS 9 Mac with Apple's free MPW.

Build it with MPW

  1. Install MPW with the Universal Interfaces. Both are free from Apple.
  2. Copy the os9, src and assets folders to the OS 9 Mac.
  3. In the MPW Shell, set the project folder as the directory and run: Execute :os9:build.mpw
  4. Open the new LocalSend application. It is designed to receive from every LocalSend device.

This version is untested on real hardware. If you try it, please tell me what happened.

Read Me

Retrofitting collects apps that bring modern things to old Macs. Each one is built to run on the real machines, with the real interface of its time: Aqua on Mac OS X 10.3 to 10.5, Platinum on Mac OS 9.

LocalSend Retro is the first. It speaks the real LocalSend protocol, so a PowerPC Mac appears in the official LocalSend app, next to your phone and your laptop.

Why you can trust it

  • The code is open and MIT licensed. Read all of it on GitHub.
  • On Mac OS X, an update only installs after its signature checks out against a key built into the app, and only after you say yes.
  • This page has no accounts, no analytics and no trackers.
  • It is an independent project, not affiliated with LocalSend.

Help test

Have a Panther or Tiger Mac, or one that still boots Mac OS 9? Try a build and open an issue with what worked and what didn't. That is the fastest way to move a build from "untested" to "working".
